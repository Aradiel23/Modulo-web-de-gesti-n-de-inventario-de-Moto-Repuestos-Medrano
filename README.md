# Módulo de inventario — Moto Repuestos Medrano (XAMPP)

**Entra a `INICIO_AQUI.txt` para instalarlo en Windows.** La versión está preparada para ubicarse en `C:\xampp\htdocs\inventario_medrano\`, iniciar **Apache** y abrir [http://localhost/inventario_medrano/](http://localhost/inventario_medrano/).

El programa está implementado con **PHP 8.1+, HTML, CSS y JSON local**. Se puede examinar con **Visual Studio Code**. No necesita Composer, Laravel ni MySQL para funcionar en esta fase académica.

- `index.php`: controlador HTTP y vistas.
- `src/store.php`: funciones de almacenamiento, validación y operaciones.
- `style.css`: estilos.
- `data/inventario.json`: datos ficticios de prueba, generados automáticamente si falta.
- `tests/pruebas_almacen.php`: pruebas automáticas.
- `GUIA_XAMPP_Y_DEFENSA.md`: instalación, demostración y preguntas de defensa.
- `database/schema_mysql.sql`: diseño preliminar MySQL **no conectado** al prototipo.

Este software es un **prototipo académico, no instalado ni validado por la empresa**. Las compatibilidades de ejemplo no deben utilizarse como recomendaciones mecánicas reales. Esta entrega no incorpora compras, ventas, facturación ni autenticación de usuarios.
